# Workflow Model

> Language: [English](workflow-model.md) · [中文](workflow-model.zh-CN.md)

The wiki skills are grouped around common knowledge-base operations:

- Ingest external sources into structured notes.
- Retrieve local context with BM25 and optional reranking.
- Query a vault with citations.
- Lint metadata, links, address counters, and structural conventions.
- Save durable session notes.
- Route new pages using a vault methodology.
- Fold log entries into higher-level pages.

Each workflow should state whether it reads, writes, fetches remote content, or
calls a model outside the local machine.
