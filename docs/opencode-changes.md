# OpenCode Changes

> Language: [English](opencode-changes.md) · [中文](opencode-changes.zh-CN.md)

The public bundle removes or rewrites assumptions from other agent runtimes:

- Tool names are described in OpenCode-compatible terms.
- Private hook references are converted to generic write-hook language.
- Legacy runtime paths are replaced with OpenCode paths.
- Token examples are placeholders.
- Vault scripts are packaged as explicit helper files.
